🏃 RUNLIFE — Corrida e Aventura

📌 Sobre o projeto

O RunLife é um projeto desenvolvido com o objetivo de apresentar o universo da corrida e da aventura, oferecendo informações, dicas e ferramentas para pessoas interessadas nessa prática esportiva.

A plataforma reúne conteúdos sobre diferentes modalidades de corrida, orientações para os treinos e uma ferramenta para calcular o ritmo médio (pace), proporcionando uma experiência visual e interativa aos usuários.

🎯 Objetivo

Desenvolver um site utilizando HTML, CSS e JavaScript, aplicando conceitos de desenvolvimento web, organização de conteúdo, interatividade e responsividade.

💻 Tecnologias utilizadas

- HTML5: estruturação e organização do conteúdo.
- CSS3: estilização, identidade visual, efeitos e responsividade.
- JavaScript: funcionalidades interativas e cálculos.

⚙️ Funcionalidades

- Carrossel de imagens: apresentação de imagens com navegação manual e automática.
- Modalidades: apresentação de diferentes formas de praticar corrida: Treino Livre, Trail Run e Corridas de Rua.
- Dicas para corredores: informações sobre hidratação, equipamentos, aquecimento e descanso.
- Calculadora de Pace: ferramenta que calcula o ritmo médio da corrida com base na distância e no tempo informado.
- Navegação interativa: menu com acesso às seções do site e botão para retornar ao início.
- Layout responsivo: adaptação dos elementos para diferentes tamanhos de tela.

🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se os arquivos CSS, JavaScript e as imagens estão organizados corretamente.
4. Abra o arquivo index.html no navegador ou utilize a extensão Live Server do Visual Studio Code.

O RunLife utiliza uma identidade visual moderna, com predominância de tons escuros e detalhes em verde, transmitindo uma proposta tecnológica e esportiva.
